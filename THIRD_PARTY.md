The node uses only the public ComfyUI `comfy_api.latest` API and NumPy in the
portable Python fallback. ComfyUI and NumPy are separate projects and retain
their own licenses and notices.

The optional native C++ weld library in `cpp/` is original WTiVo code and does
not require CUDA or a third-party geometry library.
